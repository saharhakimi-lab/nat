מהו NAT? Network Address Translation

מנגנון NAT תוכנן במקור כדי לפתור את בעיית מחסור הכתובות בפרוטוקול IPv4. המטרה: לאפשר לרשתות פרטיות פנימיות לגלוש ברשת האינטרנט הציבורית תוך שימוש בכתובת IP ציבורית אחת בלבד.

1. Static NAT סטטי

מיפוי קבוע של 1:1 בין כתובת פרטית פנימית לכתובת ציבורית חיצונית.

2. Dynamic NAT דינמי

המרת כתובת פרטית מתוך בריכת כתובות Pool ציבוריות זמינות.

3. NAT Overload / PAT ★

מאפשר לריבוי מחשבים מוצפנים לשתף כתובת ציבורית יחידה על ידי מספרי פורטים.

אזור מורה - חשיפת תשובות למבדק הידע

הזן את הסיסמה הייעודית למורה כדי לצפות בפתרונות המלאים ובמפתח התשובות.

סיסמה שגויה! נסה שוב.

מפתח תשובות נכונות 10 שאלות:
  1. ב' - חסכון בכתובות IPv4.
  2. ב' - שימוש במספרי פורטים Port Numbers.
  3. א' - מיפוי קבוע 1:1.
  4. ב' - כתובת ה-IP של היעד Destination IP.
  5. ב' - ממשק Fa0/0 172.16.1.1.
  6. ב' - 172.16.0.0/12 RFC 1918.
  7. ב' - Layer 3 IP ו-Layer 4 Port.
  8. ב' - החבילה תיזרק Dropped.
  9. ב' - הכתובת הציבורית בה נראה המחשב החוצה.
  10. א' - אבטחה בסיסית על ידי הסתרת הכתובות הפנימיות.
